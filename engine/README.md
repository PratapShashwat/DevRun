# ⚙️ StackStore: Virtualization Engine (`engine`)

## Overview
This directory tracks the evolution of StackStore's execution layer. 

### V1 Prototype (C++ Linux Namespaces)
Initially, StackStore was built using a custom, headless C++ binary that executed raw Linux `clone()` system calls (`CLONE_NEWPID`, `CLONE_NEWNS`, `CLONE_NEWUTS`) to create zero-cost namespaces. While highly performant, this restricted the application strictly to native Linux environments.

### V2 Production (Docker Orchestration)
To achieve true cross-platform compatibility (Windows, macOS, Linux) for the Microsoft AI Unlocked Hackathon, the core execution engine was pivoted to leverage the **Docker Daemon**. 

StackStore now utilizes pre-warmed, multi-ecosystem base images containing optimized runtimes for Node.js, Python 3.11, and Java. The Electron backend dynamically compiles Dockerfiles generated by Azure OpenAI on top of these base images, ensuring rapid boot times and immutable infrastructure across all operating systems. 

**Engine commands are now natively handled by `desktop_ui/src/main/index.ts`.**
